> Complete the function `IsBetween(n, low, high int) bool`. It should return `true` when `n` is within the inclusive range `low <= n <= high`, and `false` otherwise. Use comparison operators and `&&`.
>
> **Expected behavior:**
> ```go
> IsBetween(5, 1, 10) // true
> IsBetween(0, 1, 10) // false
> IsBetween(10, 1, 10) // true  (inclusive)
> ```
