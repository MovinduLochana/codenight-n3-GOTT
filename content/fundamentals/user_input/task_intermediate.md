> Fill in the `Sum` function so it reads **two integers** typed on one line using `fmt.Scan`, then returns their sum.
>
> **Example:**
> Input: `3 4` → returns `7`
>
> **Hints:**
> - Declare `var a, b int`.
> - Use `fmt.Scan(&a, &b)` — it reads space-separated values and stops at whitespace.
> - Return `a + b`.
