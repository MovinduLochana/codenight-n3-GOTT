> Implement a function named `Divide` that takes two float64 numbers (`a` and `b`) and returns a float64 (the quotient) and an error.
> - If the divisor `b` is `0.0`, return a quotient of `0.0` and a new error with the message `"cannot divide by zero"`.
> - Otherwise, return the division result and `nil` for the error.
>
> **Expected Output:**
>
> ```
> Result: 5.00
> Error: cannot divide by zero
> ```
