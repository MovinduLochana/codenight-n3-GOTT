> Implement a function `IsPalindrome(s string) bool` that checks if a string is a palindrome.
> - A palindrome is a string that reads the same backward as forward.
> - The check should be **case-insensitive** (e.g., `"Racecar"` is a palindrome).
> - In `main()`, print the results for `"Racecar"` and `"golang"`.
>
> **Expected Output:**
>
> ```
> Racecar: true
> golang: false
> ```
